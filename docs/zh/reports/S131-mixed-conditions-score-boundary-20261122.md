## 评分边界修复

实际有效替代报告保存了 `score=99.0, score_source=model_assessment`。应用消费的是 0–1 评分；原模型输出 schema 未声明区间，`ReviewAgent._overall` 又只调用 float，既会接受越界/非有限值，也会因某些非数值使完整判断归一化失败。不能据此声称模型违反了已声明的范围。

补修只在新报告的数值入账处核实有限值与 0–1 范围。bool、NaN/Infinity、溢出、非数和越界值沿已有缺评分路径变为 `None/unassessed`；保留模型 pass/partial/fail 及原理由，保留独立的执行通过率，不拿命令结果代填。合法数值和原有合法数字字符串仍兼容。**不把 99 自动除以 100，不修正模型语义结论、不重试或追加提示。**

持久 schema 保持历史兼容，旧 99 报告仍可读、原件不重写。模型系统提示、请求构造、输出 schema 与其余 ReviewAgent 方法的 AST 均对照初冻保持；仅 `_overall` 和 math import 改动，不增加认知 JSON、强制工具数、模型/格式专补或放宽权限/Accept。
