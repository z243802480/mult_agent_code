# Asteria 中文文档导航

## 1. 文档定位

本文是 `docs/zh` 的唯一导航入口。新 agent 或维护者进入项目时，先读根目录 `AGENTS.md`，再读 `docs/zh/当前状态与路线.md`，最后按本文选择需要的详细文档。

当前文档维护原则：

- 主文档只保留当前事实、长期设计和可执行计划。
- 已被吸收的调研、复盘、早期分册进入 `docs/zh/archive/`，作为历史参考，不作为当前实现依据。
- Asteria 的核心不是 dashboard 或 unrestricted chatroom，而是本地优先、可恢复、可审计、成本受控的 Runtime OS。
