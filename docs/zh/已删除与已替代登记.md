# 已删除与已替代登记

更新时间：2026-07-03
状态：current — 单一真源。任何智能体/维护者在恢复旧机制或引用旧文档前 **必读本表**。

> 目的：S61–S73 期间建了又删/又替代的机制散落在 14 条 ADR、9 段 Brief correction 和 55 份报告里，
> 导致新会话容易重新依赖已删除的东西。本表把"什么已经不存在、被什么替代"集中成一页。
> 冲突时以本表 + 代码现实为准；旧 ADR/报告仅作历史追溯。
