# 已删除与已替代登记

更新时间：2026-06-28
状态：current — 单一真源。任何智能体/维护者在恢复旧机制或引用旧文档前 **必读本表**。

> 目的：S61–S73 期间建了又删/又替代的机制散落在 14 条 ADR、9 段 Brief correction 和 55 份报告里，
> 导致新会话容易重新依赖已删除的东西。本表把"什么已经不存在、被什么替代"集中成一页。
> 冲突时以本表 + 代码现实为准；旧 ADR/报告仅作历史追溯。

## 1. 已从代码删除（不要恢复）

| 删除项 | 它曾经是什么 | 现在用什么替代 | 依据 |
| --- | --- | --- | --- |
| `RuntimeReadinessGate` | 全局事后"运行时完成度"闸门 | 风险护栏在**动作边界**强制（权限/sandbox/写/promotion）；发布预检留在 `gate-status`；定向探针直接查目标行为 | ADR-0013；Brief 2026-06-09 action-boundary correction |
| `DebugCommand` 独立修复引擎 | 第二套 repair 运行时 | `debug` 退化为 `ExecuteCommand` 定向 session 恢复的薄适配器（复用同一 Session Loop / tool gateway / candidate / 验证 / 动作边界） | ADR-0014；Brief 2026-06-09 explicit recovery correction |
| 默认 Run 自动 Review/Debug/Replan | Run 内置第二恢复控制器 | 默认恢复只由当前 Session Agent Loop 控制；Review 显式且只读（写结论/证据/反馈，不建 task/DecisionPoint/AgentLoopDecision） | ADR-0014；Brief 2026-06-09 single-session recovery correction |
| 跨目录 manifest 对齐审计（`capability_manifest_catalog_audit`） | 跨 catalog 一致性审计 | 完整 manifest 仍是审计事实；task catalog 仍是本地 dispatch 事实；权限在动作边界执行 | Brief 2026-06-09 Batch B-D convergence |
| Review follow-up keyword 策略（无产品消费者） | 失败尾巴上堆 keyword 分支 | 重大选择只能来自显式模型 ask 或具体动作边界；不为单任务加 domain keyword | ADR-0005；Brief 2026-06-09 evidence-integrity correction |
| `goal_policy` keyword 分发 | 目标关键字路由 | 模型在 Session Loop 内语义决策 | 代码已移除（grep `goal_policy` src/ 为空） |
| `runs_command.py` | 冗余 runs 列表命令 | `sessions` / `status` | Triage MERGE_OR_TRIM（DELETE） |
| 统一"低 model-call / repair 次数"硬停止 | 所有任务统一硬停止条件 | 次数/耗时是分任务 **SLO 与回归证据**，不是 Runtime 硬停止；硬闸门只保护权限/sandbox/不可逆/预算/context hard-stop/可证明无进展循环 | ADR-0010 |

## 2. 已替代（旧物仍在但不再是真源）

| 旧 | 新（当前真源） | 说明 |

## 3. 已建好但默认禁用 / 未放量（不是删除，是冻结 opt-in）

> 这些**有完整代码**但 flag 默认关、执行为 fake_serial，等真实证据 + DecisionPoint 才放量。
> 不要因"能力已实现"就默认开启，也不要再为它们新增 Wave。

| 能力 | 默认状态 | 放量前提 |
| --- | --- | --- |
| `real_disjoint_write_workers` / parallel writes | `enabled: false`（`policies.default.json`） | 真实任务证明收益 + maintainer signoff DecisionPoint |
| L3 dynamic orchestration / swarm 真并行执行 | gray off，执行 fake_serial | 同上 |
| 12 Agent 独立角色类（Architect/Product/UI/Memory/Release 等） | 仅 6 个真类（coder/debug/review/research/brainstorm/goal_spec）；其余是角色合约 | 真实收益证明 |

`readonly_fanout`（只读子代理扇出）是**例外**：已是实装产品能力，模型可在 Agent Loop 内触发。
