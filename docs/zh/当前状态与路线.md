| 层 | 当前能力 | 默认策略 |
| --- | --- | --- |
| Runtime 主路径 | Goal → Plan → Tool Use → Verify → Review/Accept | `session_agent`、bounded loop |
| 模型决策 | `tool / subagent / repair / replan / ask / stop` | 模型选择；Runtime 校验权限、安全、预算和动作一致性 |

| Workspace | candidate / merge / promotion / rollback | 单写者默认；parallel writes 仅显式 opt-in |
| Studio | session narrative、动作按钮、diff、权限卡、Inspector | 主窗口只讲用户任务进展；内部证据进入 Inspector |
| Provider | 多 provider、deadline、stream telemetry、`call_health` | fallback 成功标记 degraded，不冒充健康主路径 |
| Worker transport | 单文件 / 文档 fast path 试行 `tool_use` | 仅在 native tool-call 支持的 provider route 上灰度；2026-06-09 rolling matrix 还未证明它能稳定减少 single_file_bugfix 的额外 medium execution |
