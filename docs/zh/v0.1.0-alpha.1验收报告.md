这些阻断不否定 alpha.1 最小证明，但阻止扩大内测批次：

- `validation-run` probe 中 subagent selection、readonly fanout、readonly write-tool blocking、disjoint write unsafe fanout 和 parent loop stop 均已有 targeted 真实样本 evidence。
- `validation-run --probe-id <probe>` 已能为缺样本能力生成 targeted scoped goal 和可执行命令；P0 probe 扩面完成后，下一步应刷新 route guidance evidence，而不是继续增加同类 probe 数量。
- 2026-06-01 的 readonly targeted probe 已从“模型只完成 artifact”修正为 runtime-managed 单任务调度探针：`run-20260601-0008` 和 `run-20260601-0009` 已产出 parent `subagent` decision、`parallel_readonly_safe` child plan、2 个 readonly child worker 成功结果、validation refs 和 parent loop completed evidence。对应 summaries `.asteria/validation_runs/validation-2026-06-01T211445-0800-8ac355cf/summary.json` 与 `.asteria/validation_runs/validation-2026-06-01T211946-0800-2a0929d1/summary.json` 中 `readonly_fanout_succeeds=passed`；旧状态判定曾因 targeted probe 无 medium worker 模型调用或 run review 要求最终 artifact 而标记 failed，代码已修正 targeted probe 以目标 probe evidence 为准。2026-06-02 的 `.asteria/validation_runs/validation-2026-06-02T131519-0800-e3d1137f/summary.json` 对应 `run-20260602-0002`，进一步证明 `parent_selects_subagent`、`readonly_fanout_succeeds` 和 `parent_loop_stops_after_observation` 为 passed；`.asteria/validation_runs/validation-2026-06-02T133553-0800-35fde1ca/summary.json` 对应 `run-20260602-0004`，证明 `readonly_write_tool_blocked=passed`；`.asteria/validation_runs/validation-2026-06-02T134217-0800-c119dfcc/summary.json` 对应 `run-20260602-0005`，证明 `disjoint_write_gate_blocks_unsafe_fanout=passed`。
