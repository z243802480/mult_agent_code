# 稳态迭代节奏

更新时间：2026-06-06

面向 **Vibe coding + 模型长会话**：目标是用同一套轻量回环，让每轮迭代「跑得通、验得过、接得上」，而不是堆硬性禁令。

**机器真源**：[`benchmarks/phase4_steady_iteration_gate.json`](../../benchmarks/phase4_steady_iteration_gate.json)  
**当前 Slice**：[`benchmarks/reference_briefs/S16-steady-vibe-iteration.md`](../../benchmarks/reference_briefs/S16-steady-vibe-iteration.md)

---

## 1. 三层节奏

| 层 | 频率 | 做什么 |
| --- | --- | --- |
| **会话** | 每次 Agent / 开发 | 一个 Slice 或一个明确 bugfix；brief → 小 diff → 该 Slice 的 green_checks → 用户路径 demo |
| **周** | 维护者 | `python scripts/steady_iteration_check.py --root .` + 可选 prune |
| **阶段** | Slice 开/关 | 开：写 brief + 登记 vibe_slices；关：signoff + 三源同步 |

---

## 2. 会话回环（Vibe 友好）

```text
读 brief（Sn.md）→ 改一点 → 跑 green_checks → 演示一条用户路径 → 更新当前状态 / handoff
```

**用户路径 demo**（任选其一即算）：

- Studio：`b6-restricted-user-sim.mjs`
- CLI：`doc_update` goal → accept（见 [`S15-maintainer-dogfood-20260606.md`](./reports/S15-maintainer-dogfood-20260606.md)）
- 只读：`asteria status --json` 主路径可读

新 Slice 开工前：先补 `benchmarks/reference_briefs/Sn.md`（半页即可），再写代码。

---

## 3. 周脉搏（一条命令）

```powershell
python scripts/steady_iteration_check.py --root .
```

通过即表示：文档契约、Beta 路径契约、wheel smoke 仍绿。  
含 B6 的完整脉搏用于 **每周 / 签字前**；日常开发可用 `--skip-b6`。

本地卫生（可选）：

```powershell
python scripts/prune_local_artifacts.py --root . --dry-run
python scripts/prune_local_artifacts.py --root .
```

## 4. 三源同步（防走偏）

改 ACTIVE 状态时，同步这四处（可交给 Agent 一次改完）：

| 文件 | 改什么 |
| --- | --- |
| `AGENTS.md` | ACTIVE_SLICE / ACTIVE_PHASE 一行 |
| `docs/zh/研发总计划.md` | §16 + §3.2 快照 |
| `docs/zh/当前状态与路线.md` | §1 一句话 |
| `benchmarks/vibe_slices.json` | active_slice / active_phase |

`pytest tests/unit/test_documentation_contracts.py` 会校验三源一致。

## 5. 精力投向（S16 起）

优先让 **模型在 Harness 里稳定完成小任务**（**Studio 路径优先**）：

1. Goal → Review → Accept 更顺（B6 输出 `friction: { decide, debug, resume }`）
2. Harness：`reviewed_auto` 下低风险 runtime request 自动合并 scope
3. Studio：`runtime_request` 决策选 review_contract 后自动 resume
4. Beta 任务包 1、2 可重复 dogfood
5. 文档与测试跟着用户可见行为走，而不是先扩架构

更大方向（蜂群、North Star 自动 execute 等）留在 RFC / defer 清单；**当前阶段默认先把手头路径跑顺**。
