# 长任务进度与候选审批

更新时间：2026-05-19

## 长任务 heartbeat

真实 provider 的 `real-model-gate`、`real-model-acceptance` 和 `real-model-smoke` 链路会在等待子进程时输出低噪声 heartbeat，避免长时间无反馈。

- 默认间隔：`ASTERIA_HEARTBEAT_SECONDS=30`
- 禁用方式：`ASTERIA_HEARTBEAT_SECONDS=0`
- 输出位置：stderr
- 输出内容：当前任务、elapsed、remaining、run id、run status、model/tool call 数、最近 runtime event、最近模型 route/provider/streaming 摘要

heartbeat 只读取 `.asteria/` 中的运行元数据，不输出 prompt、模型正文、API key 或 protected paths 内容。

## 候选审批策略

`promotion.manual_approval_default` 已经具备完整运行语义。

- `false`：保持原有自动 promotion 路径，验证通过后立即尝试合并到主工作区，并记录 `auto_approved -> promoted`。
- `true`：验证通过后只写入 `pending_manual_approval`，任务进入 `blocked`，主工作区不被写入。
- 人工审批：`asteria promotions approve --promotion-id <id>`
- 拒绝或丢弃：`asteria promotions reject --promotion-id <id>` / `asteria promotions discard --promotion-id <id>`

在 `true` 模式下，candidate workspace 会保留到 operator 明确 approve/reject/discard；release gate 会继续把 unresolved promotion 视为 release blocking risk。
