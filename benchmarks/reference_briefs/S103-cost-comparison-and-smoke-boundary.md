# S103 — 固定任务成本对照与 smoke 暂停边界

## 来源与机制

总计划 §16.2、S102 报告及用户授权要求先审核剩余改动，再推送检查 CI，并用固定任务判断成本。参考 Codex/Claude Code/OpenCode 的原则：失败观察交给模型，审批和预算由运行时守住；重试不能替代权限确认。不按题目或 provider 修补结果，不降低测试判据。

## 工作与验收

- 移除尚未提交的 policy-paused 自动重试方案：日志匹配与实际 CLI 返回码不一致，且暂停不是可盲目重试的网络故障。覆盖退出码 0/1 均只运行一次，保留真实暂停状态与现有产物验证。
- 比较修复前基线 `48c08a4` 与已提交产品代码 `37516da`：同一 Linux 环境、同一既有路由、同一缺陷项目/测试/goal、auto 档及相同迭代上限，逐次独立工作区，原测试哈希固定。模型/工具/耗时、恢复次数和验证结果均记录；单次对照不推出稳定收益百分比。
- 审查更新文档，只提交明确文件；未跟踪验证目录、路由与凭据不入库。推送后按精确 commit SHA 查看 Verify jobs，不将缺 key 或运行中算通过。
- 若对照没有改善，如实保留，先分析通用上下文/工具契约和预算边界，不增加固定命令修补。
