## 参考与判断边界

- [OpenAI function calling](https://developers.openai.com/api/docs/guides/function-calling)：工具调用可与叙述分离，参数 schema 在调用边界校验；strict 对支持的模型/API 有约束，不等同于要求整段自然语言 JSON 化。
- [Anthropic 工具错误处理](https://platform.claude.com/docs/en/agents-and-tools/tool-use/handle-tool-calls)：返回可理解的错误工具结果、补足参数说明，让模型在对话里改正。
- [Anthropic 长任务 harness](https://www.anthropic.com/research/effective-harnesses-for-long-running-agents)：增量交付、明确验收清单、保留进度和验证证据，压缩本身不足以防止过早完成。
- [OpenCode 工具循环](https://raw.githubusercontent.com/anomalyco/opencode/dev/packages/ai/README.md)：非法工具参数回传模型纠正，输出截断时不执行可能不完整的调用，结构化最终输出与一般工具循环分开。
- 对照本项目：执行路径硬编码 json；解析已容忍围栏/轻微格式偏差；三次连续坏轮有保险丝。不得把持久化 schema 校验、安全 guard 和任务完成验收一起放宽，也不按模型名改写语义或静默猜工具参数。
